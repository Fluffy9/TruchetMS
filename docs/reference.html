1 Parameters

Every parameter is a number. Defaults apply when a parameter is omitted.

1.1 seed

integer · default 1 · 0 or more

Selects the layout. The same seed and parameters always produce the same mosaic.

1.2 width, height

number · default 6 · 1 to 64

Size of the repeating mosaic, in top-level cells. The pattern repeats with this period. When grade is above 0 the pattern repeats in x only, and height is not used.

1.3 levels

integer · default 4 · 0 to 8

Maximum number of times a cell may be subdivided. At 0 every cell holds one tile. Each level halves the tile size and swaps ink and ground.

1.4 split

number · default 0.5 · 0 to 1

Probability that a cell is subdivided. Not used when grade is above 0.

1.5 noise

number · default 0.45 · 0 or more

Random variation added to each subdivision decision. Higher values pull the effective split rate toward 50%, whatever split is set to. With grade above 0 it varies the size threshold instead.

1.6 style

0 or 1 · default 0

Selects the tile set. 0 is the band set, 1 is the dot set. See Tile sets.

1.7 types

bitmask · default 3 · band set only

Selects which tile families the band set may use. Each family has a value; types is the sum of the values of the families you want.

For example, arcs (1 + 2) and bars (4) give 7. All eight families give 255. Ignored when style is 1.

1.8 scale

number · default 1 · above 0

Multiplies the incoming coordinates before the mosaic is evaluated, so higher values give smaller tiles. Applies to modes 0 to 2.

1.9 grade

number · default 0 · 0 to 64

When above 0, tile size is proportional to height above y = 0, and tiles shrink toward that line. This replaces split. Nothing is drawn at or below y = 0. Required by mode 3.

1.10 mode

integer · default 0 · 0 to 3

Selects what the variation does with the incoming point. See Modes.

1.11 snap

number · default 0.4 · 0 or more

Mode 2 only. The greatest distance, in incoming units, that a point is moved to reach ink. At 0 mode 2 behaves like mode 1.

2 Modes

The mode sets how the variation treats the point it receives. In the figures, the dashed circle is the area the incoming points came from.

2.1 0 generate

Ignores the incoming point and emits a new point on ink, anywhere in the mosaic. The result is centred on the origin.

2.2 1 filter

Passes the incoming point through unchanged if it is on ink. If it is on ground the point is discarded. The tiles act as a stencil over whatever came before.

2.3 2 snap

Passes the incoming point through if it is on ink. If it is on ground, the point is moved to nearby ink, no further than snap. If no ink is found nearby the point is discarded. Compared with filter, fewer points are lost and the shape's edges are softened.

2.4 3 disk

Emits points on the ink of the hyperbolic mosaic, inside the unit Poincaré disk. Requires grade above 0. The rim of the disk corresponds to y = 0.

2.5 Host support

HostModes
Fireheart0, 1, 2, 3
Apophysis 7X0

Apophysis variations cannot discard a point. Modes 1 and 2 discard points that land on ground, so they are not suited to it. Mode 0 does not depend on the incoming point and emits a point on ink, so it works there.

3 Tile sets

Both sets use the same square cells and the same subdivision. They differ in how a tile meets its neighbours: the band set joins them with a wide strip of ink, the dot set with two dots. A tile only joins tiles of its own set, so the sets cannot be mixed.

3.1 Band set

style 0 · 15 tiles

Christopher Carlson's tiles. Strokes are one third of a cell wide, and every edge carries ink along its middle third, so neighbours join strip to strip. Families are enabled with types.

3.2 Dot set

style 1 · 22 tiles

Built from circles. Each edge carries two ink dots, at one quarter and three quarters of its length, so neighbours join dot to dot. Strokes are one sixth of a cell wide. Some tiles have two or four distinct rotations. types is ignored.

4 Installation

  • Fireheart. Built in.
  • Apophysis 7X. Copy truchet_ms.dll (x64 or x86 to match Apophysis) from the releases page into the Plugins folder and restart. Requires Windows 10 or later.
  • WebAssembly. truchet_plugin.wasm, loaded with loadLiveModule.
  • Rust. The truchet-tiles crate. See the API documentation.
